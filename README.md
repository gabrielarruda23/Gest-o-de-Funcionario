 Sistema de Gestão de Funcionários - DevStartup

Sistema simples em **HTML + JavaScript + Tailwind** para gerenciamento de funcionários de uma startup.
 Funcionalidades
- Cadastrar, listar, editar e excluir funcionários
- Exportar lista para CSV
- Relatórios dinâmicos com `map`, `filter`, `reduce`
- Persistência local com `localStorage`

 Execução
Abra o arquivo `index.html` diretamente no navegador.
